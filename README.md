Título do Jogo: Subindo os Andares

Gênero: Plataforma 2D / Ação

Descrição:

É um jogo de plataforma 2D que se passa em um prédio em obras. O jogador assume o papel de um técnico de manutenção em um desafio de reflexos rápidos,
onde o objetivo é sobreviver ao caos e coletar todas as maletas perdidas!
