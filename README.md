# Subindo-os-Andares
Título do Jogo: Subindo os Andares

Gênero: Plataforma 2D / Ação

Descrição:

É um jogo de plataforma 2D, que se passa em um prédio em obras. 
O jogador vira um técnico de manutenção o  desafios é de reflexo rápido, e o objetivo é sobreviver ao caos e coletar todas as maletas perdidas!
