# Subindo-os-Andares
Título do Jogo: Subindo os Andares

Gênero: Plataforma 2D / Ação

Descrição:

É um jogo de plataforma 2D dinâmico ambientado em um prédio em obras. 
O jogador vira um técnico de exploração precisa de andares coletando maletas de ferramentas. 
Com uma jogabilidade arcade frenética e desafios de reflexo rápido, o objetivo é sobreviver ao caos e coletar todas as maletas perdidas!
